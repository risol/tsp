# Route examples

These fixtures are small, focused examples of the current `.tsp` contract.
They are source files rather than a runnable tutorial application.

| Example | Demonstrates |
| --- | --- |
| [`01-hello.tsp`](./01-hello.tsp) | Minimal JSX route |
| [`02-login.tsp`](./02-login.tsp) | Form and request handling |
| [`03-api-users.tsp`](./03-api-users.tsp) | JSON API response |
| [`04-user-detail.tsp`](./04-user-detail.tsp) | Dynamic route parameters |
| [`05-list-with-fragment.tsp`](./05-list-with-fragment.tsp) | Fragment URLs |
| [`06-async-component.tsp`](./06-async-component.tsp) | Async components |
| [`07-trusted-html.tsp`](./07-trusted-html.tsp) | Explicit raw HTML boundary |
| [`08-catch-all.tsp`](./08-catch-all.tsp) | Catch-all route mapping |
| [`09-no-tsp-imports.tsp`](./09-no-tsp-imports.tsp) | Shared module boundary |
| [`10-shape-magic.tsp`](./10-shape-magic.tsp) | Invalid response shapes |

The repository's `pages/` directory contains additional end-to-end fixtures
for cookies, sessions, services, uploads, timeouts, SQL, and diagnostics.
